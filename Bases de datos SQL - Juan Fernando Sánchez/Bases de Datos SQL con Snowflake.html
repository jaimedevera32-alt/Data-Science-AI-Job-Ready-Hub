HITO 1: Bases de Datos Relacionales e Introducción a Snowflake
El primer hito del curso establece los fundamentos esenciales de las bases de datos relacionales y te introduce en el ecosistema Snowflake.
Tema 1: Introducción a Bases de Datos Relacionales
Conceptos fundamentales: tablas, filas, columnas, tipos de datos y relaciones. Lenguaje SQL: DDL (Definición) y DML (Manipulación de datos).
Tema 2: Modelado de Datos
Diseño Conceptual (Modelo ER), Diseño Lógico (transformación a tablas) y Diseño Físico (implementación SQL).
Tema 3: Gestión con Snowflake
Introducción a la plataforma: escalabilidad, seguridad, almacenamiento y configuración inicial.
HITO 2: Dominando SQL en Snowflake
En este hito profundizarás en el lenguaje SQL aplicado específicamente al entorno Snowflake, desarrollando habilidades avanzadas de consulta y manipulación de datos.
Creación y Transformación de Tablas
DDL (CREATE, ALTER, DROP) y DML (UPDATE, DELETE)
Sintaxis DML
SELECT (ALIAS, DISTINCT, WHERE, Funciones y GROUP BY)
Combinación de Tablas
Uso de los diferentres tipos de JOINs para combinar tablas mediante claves primarias
Funciones Avanzadas
Subconsultas , Funciones de Ventana, HAVING, CASE WHEN, Operadores de conjunto UNION.
The Extra Mille
Utilización avanzada de Common Table Expression (CTEs), SelfJOINs y Combinación de VIEWs.
El dominio de estos elementos te permitirá realizar consultas sofisticadas, transformar datos eficientemente y extraer información valiosa de conjuntos de datos complejos en Snowflake.
HITO 3: Proyectos Prácticos
Aplica tus conocimientos en proyectos reales que simulan entornos profesionales, utilizando datasets específicos y desarrollando soluciones SQL avanzadas.
Proyecto ONU
Análisis aplicado sobre datasets específicos de desarrollo humano, población y días libres pagados utilizando consultas SQL avanzadas en Snowflake.
Caso Práctico: Planet Express
Segmentación práctica de clientes a través del análisis de pedidos y creación de vistas segmentadas para perfilado de clientes.
HITO 4: Tarea Final (Smart Desk)
La culminación práctica del curso donde integrarás todos los conocimientos adquiridos para realizar un análisis integral de datos empresariales.
Presentación del Caso
Dominamos a la perfección las necesidades de nuestros clientes y su proceso de ventas al por mayor de soluciones ergonómicas en todo el mundo.
Preguntas de Negocio
Análisis detallado de preguntas comerciales, costes y precios, para calcular márgenes y rentabilidad por producto.
Generación de Insights
Extracción de valor a partir de datos reales mediante la combinación de técnicas avanzadas SQL para obtener conclusiones de negocio.
Caso Práctico
Implementarás una funcionalidad propia que abarca todo el ciclo de vida de los datos: desde el análisis exploratorio y el desarrollo SQL, hasta la obtención y validación de resultados, seguidos de pasos estratégicos de negocio alineados con los resultados.
